# Firebase Trigger Viewer
The idea is to standardize a way of recording firebase trigger sources and what they do, while simultaneously providing a glanceable visual to see them.

[Live Demo](https://json-link-viewer.pages.dev/)

The goal is to leverage existing patterns in diagram-as-code languages.

At the very least, the plain text itself should provide enough information to be useful.

```
path/to/{dynamic}/trigger/source -> path/to/{dynamic}/trigger/effect : Relationship between the source and effect
path/to/{dynamic}/trigger/source -> path/to/{dynamic}/trigger/effect : Relationship between the source and effect
path/to/{dynamic}/trigger/source -> path/to/{dynamic}/trigger/effect : Relationship between the source and effect
```
